🌍 Travel Catalog – Django Application
📌 Overview

Travel Catalog is a web-based travel destination listing application built using Django.
The application allows users to browse travel destinations and view detailed information dynamically from the database.

This project demonstrates Django backend fundamentals including database modeling, dynamic template rendering, and admin configuration.

----------------------------------------------------------------------------------------------------------------------------------------

🚀 Features

Destination listing page

Detailed destination view

Admin panel for managing destinations

Dynamic content rendering using Django templates

Responsive frontend design
